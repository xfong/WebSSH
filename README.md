# WebSSH

A browser-based SSH terminal and X11 GUI application platform for cluster access. Users authenticate via LDAP, access persistent SSH terminal sessions, and run X11 GUI applications — all from any browser, including mobile and tablet devices.

---

## Features

- **LDAP authentication** with LDAPS-first, plain LDAP fallback
- **Persistent SSH sessions** that survive browser close
- **X11 GUI streaming** via Xpra HTML5 client, each app in its own browser tab
- **Session hierarchy tree** (Windows Explorer-style) with real-time updates
- **Virtual QWERTY keyboard** with sticky modifier keys (Ctrl, Alt, Shift, Meta)
- **Mouse button panel** (Left, Middle, Right click; Scroll Up/Down)
- **Dark / Light / System theme** toggle
- **Admin control panel** — observe, gracefully terminate, or force-kill any user session
- **Docker Compose** deployment on Ubuntu 24.04 LTS

## Prerequisites

All prerequisites are installed automatically by running `prereq.sh` (see Installation below). For reference, the script installs the following on Ubuntu 24.04 LTS:

| Package | Minimum Version | Purpose |
|---|---|---|
| Docker Engine | v24+ | Container runtime |
| Docker Compose v2 | v2.0+ | Multi-container orchestration |
| OpenSSL | Any | Self-signed TLS certificate generation |
| Node.js | v18+ | Frontend build and admin password hashing |
| npm | Bundled with Node.js | Package management |
| OpenSSH client | Any | SSH connectivity testing |
| bcrypt (npm) | v5+ | Admin password hashing during setup |
| git | Any | Repository cloning |

## Installation

```bash
# 1. Install all prerequisites (Docker, Node.js, OpenSSL, etc.)
#    Must be run as root on the target server, BEFORE cloning.
curl -fsSL https://raw.githubusercontent.com/xfong/WebSSH/main/scripts/prereq.sh | sudo bash

# 2. Log out and back in to activate docker group membership, then:

# 3. Clone the repository
git clone https://github.com/xfong/WebSSH.git
cd WebSSH

# 4. Build the frontend
cd frontend && npm install && npm run build && cd ..

# 5. Run the setup script
bash scripts/setup.sh
```

The `setup.sh` script will:

1. Prompt for LDAP server details, admin credentials, and SSH host configuration.
2. Generate a self-signed TLS certificate for HTTPS.
3. Write a `.env` configuration file.
4. Build and start all Docker containers via `docker compose up -d`.

After setup, open `https://<your-server-hostname>` in your browser. Accept the self-signed certificate warning on first visit.

---

## Configuration

All runtime configuration is stored in the `.env` file generated by `setup.sh`. Refer to `.env.example` for a full list of available options with descriptions. To reconfigure, edit `.env` and run `docker compose restart app`.

---

## Admin Account

The administrator account is a local account (not LDAP). Its username and bcrypt-hashed password are set during `setup.sh`. The admin logs in via the same login page as regular users and is routed to the session management view automatically.

---

## Security Notes

- The self-signed TLS certificate is valid for 10 years. Replace it with a certificate from your internal CA if available.
- The LDAP CA certificate must be placed at the path specified in `.env` (`LDAP_CA_CERT_PATH`) and mounted into the backend container.
- The `.env` file contains sensitive secrets. Ensure it is not committed to version control (it is listed in `.gitignore`).
- User SSH passwords are held in Redis with a 5-minute TTL solely for the purpose of establishing the SSH connection. They are never logged or persisted beyond this window.
